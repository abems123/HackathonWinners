# Payroll closing checklist

Checklist for consultants at month end.

1. Remind the client to send their input by the **3rd working day** of the next month.
2. Check absences in PayLink against the client's absence overview.
3. Import the input file into PayLink.
4. Run a test calculation and check gross-to-net for new employees.
5. Launch the final run.

Not sure about something? Ask Marc Peeters.
