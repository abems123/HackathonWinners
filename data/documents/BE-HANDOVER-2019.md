# Client portfolio handover guide

When a client moves to another payroll consultant:

1. The current consultant writes one handover document per client, using the attached template.
2. Plan a one-hour meeting between the current and the new consultant to go through the document.
3. Send an e-mail to the client to introduce the new consultant.

That's it. The handover document contains everything the new consultant needs.
